Truline demo · voice-over, shot by shot

Pick a shot below0.0 s
Record each shot on its own; re-record any of them until you're happy, then download.

Each take records only its shot's window (with a 3-second countdown) and is saved as voice_NN_id.webm. Put the downloads in video/out/ and run uv run --python 3.11 --with imageio-ffmpeg python video/merge_voice.py: each take is placed at its shot's start time. Use headphones so the preview doesn't bleed into the mic.
